# QA manual — páginas públicas

Roteiro permanente das páginas que qualquer visitante vê, organizado pelos mesmos domínios de [`docs/dominios/`](../dominios/). Rode as seções afetadas sempre que uma release mudar UI — é o check "Fluxos afetados testados no preview; screenshots quando visual" da seção 2 do [WORKFLOW](../../WORKFLOW.md) — e o roteiro inteiro numa rodada completa de testes. Como usar os roteiros, registrar divergências e ler a coluna Cobertura está no [índice de QA](./README.md). O que cada página faz não se repete aqui: cada seção linka o domínio correspondente.

Quando a Cobertura diz entre parênteses o que o teste cobre (por exemplo "decisão; exibição manual"), o teste garante só a regra, e a parte visual continua precisando do navegador. Importação, limpeza e automação ficam em [`importacao.md`](./importacao.md).
