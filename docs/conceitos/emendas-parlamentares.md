# Emendas parlamentares

Emendas são alterações que parlamentares fazem ao Orçamento da União para destinar recursos a finalidades específicas — geralmente para suas bases eleitorais.

## Tipos

- **Individuais** — cada deputado/senador tem uma cota anual. Hoje **impositivas** (governo é obrigado a pagar).
- **De bancada** — propostas pela bancada estadual de cada estado. Também impositivas.
- **De comissão** — propostas pelas comissões permanentes do Congresso.
- **De relator** — historicamente as mais polêmicas ("orçamento secreto", RP-9). Hoje sob restrições.

## Como o dinheiro chega

1. **Via convênio tradicional** — entra no SICONV / Transferegov.
2. **Via transferência especial** (EC 105/2019, "emenda Pix") — vai direto para o ente, sem finalidade definida. Muito mais opaca: o ente pode usar quase como recurso próprio.
3. **Via transferência com finalidade definida** (EC 105/2019) — vai direto, mas com finalidade ampla informada pelo autor.

## Por que "emenda Pix" preocupa

Antes da EC 105, todo repasse precisava de convênio com plano de trabalho, fiscalização da Caixa, prestação de contas detalhada. Com transferências especiais, o controle migra quase todo para o ente recebedor — frequentemente uma prefeitura pequena sem capacidade de fiscalização.

O site mostra essas transferências em `/transferencias` exatamente para criar visibilidade externa.

## Quem é o "autor"

Em emendas individuais, o autor é um único parlamentar. Em emendas de bancada, é a bancada inteira de um estado. A rastreabilidade do autor é uma conquista recente — antes da EC 105 era mais difícil saber quem indicou o quê.
