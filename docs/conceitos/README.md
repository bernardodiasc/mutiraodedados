## Por que isso importa

Cada número que aparece no site tem uma história no mundo real: foi assinado por um gestor, executado por uma empresa, fiscalizado (ou não) por um órgão de controle, e tem uma lei por trás. Quando o sistema agrega esses números, é fácil esquecer disso.

Estes textos existem para lembrar.
