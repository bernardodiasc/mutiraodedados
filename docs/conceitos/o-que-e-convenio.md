# O que é um convênio

Convênio é um acordo entre o governo federal (ou estadual) e outro ente (estado, município, ONG) para executar uma política pública conjuntamente. Não é compra de bem ou serviço — é repasse com finalidade definida.

## Atores

- **Concedente** — quem repassa o dinheiro (em geral, União via ministério).
- **Convenente** — quem recebe e executa (prefeitura, governo estadual, OSC).
- **Interveniente** (opcional) — terceiro que participa de algum modo.

## Tipos parecidos

- **Convênio** (Lei 8.666/Decreto 6.170): instrumento clássico.
- **Contrato de repasse**: similar, mas mediado por agente operador (geralmente Caixa).
- **Termo de fomento / colaboração** (Lei 13.019 / MROSC): com OSCs.
- **Transferências especiais** (EC 105/2019): "emendas Pix", sem finalidade definida.
- **Transferências com finalidade definida** (EC 105/2019): finalidade ampla definida pelo parlamentar.

## Estrutura financeira

- **Valor global** — total previsto.
- **Valor de repasse** — parte da União.
- **Valor de contrapartida** — parte do convenente (próprio ou de terceiros).

Quando essas três partes não fecham (ex: repasse + contrapartida ≠ global), o sistema marca como QA finding.

## Plano de trabalho

Documento que detalha **o que** o convenente vai fazer com o dinheiro: metas, etapas, cronograma. Disponível no Transferegov quando há código SICONV.

## Por que importa

Convênios são uma das principais formas de o governo federal financiar políticas locais — saúde básica, asfalto, escolas. Acompanhar é essencial para entender se o dinheiro chegou onde devia.

## Leis relevantes

- **Decreto 6.170/2007** e **Portaria Interministerial 424/2016** — regulamentam convênios e contratos de repasse.
- **Lei 13.019/2014** (MROSC) — parcerias com OSCs.
- **EC 105/2019** — criou transferências especiais ("emendas Pix") e com finalidade definida.
